# Bewohner-Status Kachel

![Bewohnerstatus-Kachel](https://raw.githubusercontent.com/da8ter/images/refs/heads/main/bewohnerstatus.png)

Diese Kachel zeigt den Anwesenheitsstatus beliebig vieler Bewohner mit Foto und Namen an. Der Status kann auch durch Klicken auf das Bild umgeschaltet werden.
